System Radius—same input unit

Formula

System Radius = Drum Diameter ÷ 2
System Turn Ratio = System Radius ÷ Belt Width

Because both dimensions use the same unit, the turn ratio has no unit.

Engineering Guidelines

1

A belt with a minimum turn ratio greater than the calculated system turn ratio will not work in this spiral.

2

Using a belt with a minimum turn ratio more than 0.30 below the system turn ratio is not recommended.

Engineering Disclaimer

This calculator is intended for preliminary engineering estimates and reference only. Verify all dimensions, belt specifications, manufacturer requirements, and operating conditions before selecting or installing a belt.
